## 🕹️ About the Game

This project is a recreation of the classic **Tetris** game built using Python and Pygame.

The game features falling Tetris pieces, player-controlled movement, piece rotation, line clearing, and score tracking. The project was created to practice **object-oriented programming, game logic, collision detection, and working with Pygame**.

---

## ✨ Features

* 🧱 Classic Tetris gameplay
* 🎮 Player-controlled piece movement
* 🔄 Piece rotation
* ⬇️ Soft drop
* 💥 Line clearing
* 🏆 Score tracking
* 🧩 Multiple Tetris piece shapes
* ⏱️ Automatic piece falling
* 🎯 Collision detection
* 🛑 Game-over detection

---

## 🎮 Controls

| Key                 | Action           |
| ------------------- | ---------------- |
| ⬅️ A or Left Arrow  | Move piece left  |
| ➡️ D or Right Arrow | Move piece right |
| ⬇️ S or Down Arrow  | Move piece down  |
| ⬆️ W or Up Arrow    | Rotate piece     |
| `SPACE`             | Hard drop        |
| `ESC`               | Quit game        |

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/TetrisGame.git
```

### 2. Navigate into the project

```bash
cd TetrisGame
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the game

```bash
python TetrisGameV2.py
```
